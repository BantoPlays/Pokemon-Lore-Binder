OUR POKÉMON CARD BINDER — SHARED VERSION

This is the online-sync version.

270 total slots:
- 201 regular
- 59 secret rares
- 10 promos

Features:
- Large card slots
- Bulbasaur + Snorlax corner artwork
- Search
- Upload / edit / remove
- Card names and notes
- Live shared synchronization with Firebase Firestore
- Anonymous authentication
- Progress tracking
- Export/import backups

START HERE:
1. Open FIREBASE_SETUP.md
2. Create a Firebase project.
3. Put your Firebase web config in firebase-config.js.
4. Enable Anonymous Authentication.
5. Create Firestore and use the security rules in FIREBASE_SETUP.md.
6. Upload the project to GitHub.
7. Turn on GitHub Pages.
